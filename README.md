# AI Diet Planning Chatbot

An AI-powered diet recommendation system built using Streamlit and Google Gemini AI.  
The chatbot generates personalized diet plans based on a user's weight, fitness goals, and dietary preferences.

The application provides:
- Meal planning
- Calorie breakdown
- Macronutrient distribution
- Portion sizes
- Alternative food suggestions

---

## Features

- Personalized AI-generated diet plans
- Supports multiple fitness goals:
  - Weight Loss
  - Muscle Gain
  - General Fitness
- Supports various dietary preferences:
  - Vegetarian
  - Vegan
  - Non-Vegetarian
  - Keto
  - Balanced Diet
- Calorie and macronutrient breakdown
- Simple and easy-to-follow meal recommendations
- Interactive Streamlit user interface

---

## Tech Stack

- Python
- Streamlit
- Google Gemini AI

---

## Project Workflow

1. User enters:
   - Weight
   - Fitness goal
   - Dietary preference
2. The application generates a structured prompt
3. Gemini AI creates a personalized diet plan
4. The plan is displayed with meals, nutrients, and recommendations
